События и мобы

/nuke [секунды] [радиус]: ядерный удар по месту, где стоишь. По умолчанию 90 секунд и радиус 250.
/nuke cancel: отменить ядерный удар.
/taboritsky [штурмовики] [секунды]: Таборицкий с конвоем. По умолчанию 6 штурмовиков, через 90 секунд приходит царь Алексей.
/gorynych: Змей Горыныч приходит.
/skyturtle [кол-во]: прилетает Лаич Па.
/droneattack [кол-во] [player]: атака шахедов, по умолчанию 6 дронов.
/droneattack stop: отменить атаку дронов.
Катсцены

/aidimduel start [player]: дуэль с Айдимом на консолях.
/aidimduel stop: прервать дуэль.
/aidimduel reset: снова разрешить одноразовую дуэль в этом мире.
/coronation [player]: коронация Алексея.
/finale [player]: финал «ВЫ ПРОШЛИ МАЙНКРАФТ».
/island cutscene [player]: катсцена в храме.
Время

/timestop [секунды] [player]: остановка времени. Указанные игроки могут двигаться.
/timestop stop: снять остановку времени.
/madeinheaven: дни и ночи проносятся мимо
/madeinheaven stop: остановить смену дней.
Острова

/island tp [player]: телепорт на остров.
/island where: координаты острова.
/island create: построить остров там, где стоишь.
/island rebuild: перестроить остров на том же месте.
/island men: Джефри и Трамп лучшие друзья.
/island reset: снова разрешить событие в храме.
/island2 tp [player]: телепорт на второй остров.
/island2 donation [player]: телепорт на второй остров, но только в первый раз.
/island2 donation reset: следующий донат снова телепортирует.
/island2 where: координаты второго острова.
/island2 rebuild: перестроить второй остров.
/island2 men: Джефри и Трамп лучшие друзья.
