# Baranus Chaos

Аналог Chaos Tricks для Minecraft 1.20.1 (Forge). Зритель донатит через DonationAlerts сумму, и в игре происходит ивент с такой ценой. Можно играть вдвоём: два стримера, у каждого свои донаты, общий набор ивентов.

## Установка

1. Положите `baranus-chaos-forge-1.5.3.jar` и `chaosmobs-1.0.0.jar` в папку `mods` своего Minecraft (и сервера, если играете на сервере). Нужны Minecraft 1.20.1, Forge 47.4.10+ и Java 17. Те же моды нужны всем, кто заходит в ваш мир, - в том числе другу, который не стримит: ему достаточно модов, приложение не нужно.
2. Запустите `Baranus-Chaos-1.6.1.exe`

## Подключение

1. **Подключения → «Войти через DonationAlerts».** Откроется браузер, нажмите «Разрешить».
   - Если вход не проходит, создайте своё приложение на [donationalerts.com/application/clients](https://www.donationalerts.com/application/clients) с адресом перенаправления ровно `http://127.0.0.1:3217/oauth/callback` (это адрес вашего же компьютера) и впишите Client ID и Client Secret в «Своё приложение DonationAlerts».
   - Если подписка DonationAlerts в реальном времени не работает, донаты проверяются каждые 5 секунд через список донатов.
2. **Подключения → Minecraft:**
   - **«Свой мир»** (по умолчанию) — откройте любой мир с модом, приложение подключится само, пароль не нужен.
   - **«Мир друга»** — играете в мире другого стримера (см. «Совместная игра»).
   - **«Сервер»** — сервер на другом компьютере.
3. **Ивенты.** Проверьте цены, переименуйте ивенты под себя или создайте свои.

### Сервер на другом компьютере

Выберите «Сервер» и включите RCON в `server.properties` сервера:

```properties
enable-rcon=true
rcon.port=25575
rcon.password=длинный_пароль
```

## Совместная игра (Radmin VPN)

Оба стримера запускают своё приложение и подключают свой DonationAlerts.

1. Оба устанавливают [Radmin VPN](https://www.radmin-vpn.com/ru/) и заходят в одну сеть.
2. **Хозяин мира:** открывает мир → Esc → «Открыть для сети» (запомните порт из чата), затем в приложении **Подключения → «Совместная игра» → «Разрешить подключение друга»**. Там же видны адрес Radmin (26.x.x.x) и код доступа (8 букв и цифр) — их нужно передать второму стримеру. Если Windows спросит про доступ Java к сети, разрешите.
3. **Второй стример:** заходит в мир через «Сетевая игра» по адресу `адрес_Radmin:порт`, а в приложении выбирает **«Мир друга»** и вписывает адрес Radmin и код доступа. Порт из чата нужен только для входа в мир в самом Minecraft.

Настройки ивентов (цены, валюты, очередь, свои ивенты) хранятся в мире и синхронизируются: правка у любого из стримеров сразу появляется у другого.

- Надписи и эффекты ивента видят и получают **оба** стримера.
- Мобы и прочие «точечные» ивенты появляются **рядом со стримером, чей зритель задонатил**. Для каждого ивента это можно поменять в редакторе: «Кому срабатывает» → «Стримеру, которому пришёл донат» или «Всем стримерам в мире».
- Очередь общая: ивенты двух приложений не накладываются друг на друга.

## Как срабатывают ивенты

- Донат **ровно** на сумму цены запускает ивент: 20 ₽ — «Зомби». Другие суммы остаются обычными донатами.
- **Очередь.** Ивент срабатывает не сразу, а через задержку после доната (по умолчанию 30 с). Если в очереди уже есть ивент, следующий встаёт ещё на 30 с позже, чтобы предыдущий успел отыграть; то же действует между приложениями двух стримеров. Задержка - в «Ивенты → Очередь». Ожидающие ивенты видны на панели: их можно запустить сразу (▶) или отменить (✕).
- **Зрители из других стран.** В «Ивенты → Валюты зрителей из других стран» включите доллары ($) и/или евро (€). Курс подтягивается из интернета автоматически (ExchangeRate-API, обновляется несколько раз в сутки), и цены ивентов в этих валютах считаются по нему с округлением вверх до цента (например, 49 ₽ → 0,55 $). Цены в рублях - только целые, в долларах и евро - с копейками. Донат в долларах сравнивается с долларовой ценой. Любую цену можно задать вручную в редакторе ивента (✎); «Сбросить ручные цены» возвращает расчёт по курсу.
- Если валюта доната не добавлена, приложение берёт пересчёт DonationAlerts в основную валюту (если он есть).
- Если у нескольких ивентов одна цена, выпадает случайный из них.
- Код в сообщении, например `!creeper`, выбирает конкретный ивент, если суммы хватает. Это можно отключить.
- **Пауза хаоса**: кнопка в приложении или клавиша **K** в игре. Донаты во время паузы попадают в ленту, и их можно запустить кнопкой «↻ Запустить».

## Настройка ивентов

- **Вид:** плитки или список, поиск по названию и сортировка (по порядку, по цене, по названию).
- **«⧉ В отдельном окне»** открывает компактный список ивентов: включить или выключить, поменять цену, открыть настройки (✎).
- В редакторе ивента (✎):
  - **Кому срабатывает** — стримеру, которому пришёл донат, или всем стримерам в мире.

## Свои ивенты

**Ивенты → «＋ Создать ивент»**: название, цена, описание и команды Minecraft, по одной в строке (до 10).

- `{player}` — ник стримера, `{donor}` — имя зрителя.
- Команды выполняются от имени игрока, поэтому `~ ~ ~` означает «рядом с ним». Права как у OP 2-го уровня: `/op`, `/stop` и подобные недоступны.
- Пример: `effect give {player} minecraft:levitation 5 1` и `say {donor} отправил меня в полёт!`
- Кнопка «▶ Проверить» в редакторе сразу запускает ивент в игре.

У встроенных ивентов через «✎» можно поменять название, описание и цену. «Вернуть исходное» отменяет переименование.

## Меню ивентов в игре (клавиша K)

Все ивенты с ценами из приложения, поиском и вкладками по категориям (Помощь, Пакости, Мобы, Хаос, Свои). Наведите на ивент — подсказка покажет описание, кому оно срабатывает и перезарядку.

- **Хозяин мира и OP:** щелчок по ивенту — проверить на себе, переключатель — включить или выключить ивент (изменение сразу уходит в приложения обоих стримеров). Значок «ХАОС АКТИВЕН» вверху ставит хаос на паузу и снимает её.
- **Остальные игроки** видят меню только для просмотра.

Мобы получают ник зрителя, а на экране у всех игроков появляется заголовок «Ивент — от Ник».

## Разработка

- Node.js 22+: `npm test`, `npm start` (панель в браузере), `npm run desktop`, `npm run dist` (EXE).
- Мод: из папки `forge-mod` командой `gradle build` (Gradle 8.8, Java 17).
- Иконка: `build/icon.ico` (EXE), `public/icon.png` (интерфейс).
- Шрифт интерфейса: [Monocraft](https://github.com/IdreesInc/Monocraft) (SIL Open Font License 1.1, `public/fonts/OFL.txt`).
