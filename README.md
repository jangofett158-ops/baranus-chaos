# Baranus Chaos

Аналог Chaos Tricks для Minecraft 1.20.1 (Forge). Зритель донатит через DonationAlerts сумму, и в игре сразу происходит событие с такой ценой. Очереди нет: каждый донат выполняется немедленно и независимо от остальных.

## Установка

1. Положите `baranus-chaos-forge-1.2.0.jar` в папку `mods` своего Minecraft (и сервера, если играете на сервере). Нужны Minecraft 1.20.1, Forge 47.4.10+ и Java 17.
2. Запустите `Baranus-Chaos-1.2.2.exe`. Установка не нужна — это одиночный файл, его можно положить в любую папку.

## Подключение

1. **Подключения → «Войти через DonationAlerts».** Откроется браузер, нажмите «Разрешить».
   - Если вход не проходит, создайте своё приложение на [donationalerts.com/application/clients](https://www.donationalerts.com/application/clients) с адресом перенаправления ровно `http://127.0.0.1:3217/oauth/callback` (это адрес вашего же компьютера) и впишите Client ID и Client Secret в «Своё приложение DonationAlerts».
   - Если подписка DonationAlerts в реальном времени не работает, донаты проверяются каждые 5 секунд через список донатов.
2. **Подключения → Minecraft → «🏠 Локальный мир»** (по умолчанию). Откройте любой мир с модом: приложение подключится само, RCON и пароль не нужны.
3. **События.** Проверьте цены, переименуйте события под себя или создайте свои.

### Сервер на другом компьютере

Выберите «🌐 Сервер (RCON)» и включите RCON в `server.properties` сервера:

```properties
enable-rcon=true
rcon.port=25575
rcon.password=длинный_пароль
```

## Как срабатывают события

- Донат **ровно** на сумму цены запускает событие: 20 ₽ — «Зомби». Другие суммы остаются обычными донатами.
- **Зрители из других стран.** В «События → Валюты зрителей из других стран» добавьте нужные валюты (USD, EUR, UAH, KZT, BYN, PLN, TRY, BRL) и укажите курс к основной валюте. Цены событий в этих валютах считаются по курсу (например, 20 ₽ при курсе 90 — это 0,22 $), а донат в долларах сравнивается с долларовой ценой. Любую цену можно задать вручную в редакторе события (✎). Кнопка «↻ По курсу» сбрасывает ручные цены. Курсы примерные, поправьте их под себя.
- Если валюта доната не добавлена, приложение берёт пересчёт DonationAlerts в основную валюту (если он есть).
- Если у нескольких событий одна цена, выпадает случайное из них.
- Код в сообщении, например `!creeper`, выбирает конкретное событие, если суммы хватает. Это можно отключить.
- **Пауза хаоса**: кнопка в приложении или клавиша **K** в игре. Донаты во время паузы попадают в ленту, и их можно запустить кнопкой «↻ Запустить».

## Свои события

**События → «＋ Создать событие»**: название, эмодзи, цена, описание и команды Minecraft, по одной в строке (до 10).

- `{player}` — ник стримера, `{donor}` — имя зрителя.
- Команды выполняются от имени игрока, поэтому `~ ~ ~` означает «рядом с ним». Права как у OP 2-го уровня: `/op`, `/stop` и подобные недоступны.
- Пример: `effect give {player} minecraft:levitation 5 1` и `say {donor} отправил меня в полёт!`
- Кнопка «▶ Проверить» в редакторе сразу запускает событие в игре.

У встроенных событий через «✎» можно поменять название, иконку, описание и цену. «Вернуть исходное» отменяет переименование.

## В игре (клавиша K)

Доступно OP на сервере и хозяину одиночного мира (даже без включённых читов): пауза хаоса, проверка встроенных событий на себе, кнопка «Убрать мобов». Мобы получают ник зрителя, а на экране появляется заголовок «Событие — от Ник».

## Разработка

- Node.js 22+: `npm test` (50 тестов), `npm start` (панель в браузере), `npm run desktop`, `npm run dist` (EXE).
- Мод: из папки `forge-mod` командой `gradle build` (Gradle 8.8, Java 17).
- Иконка: `build/icon.ico` (EXE), `public/icon.png` (интерфейс).
