# Baranus Chaos

Аналог Chaos Tricks для Minecraft 1.20.1 (Forge). Зритель донатит через DonationAlerts сумму, и в игре происходит событие с такой ценой. Можно играть вдвоём: два стримера, у каждого свои донаты, общий набор событий.

## ⬇️ Скачать

- **Приложение для Windows (x64):** [Baranus-Chaos-1.5.1.exe](https://github.com/jangofett158-ops/baranus-chaos/releases/download/v1.5.1/Baranus-Chaos-1.5.1.exe)
- **Мод для Minecraft 1.20.1 (Forge):** [baranus-chaos-forge-1.5.1.jar](https://github.com/jangofett158-ops/baranus-chaos/releases/download/v1.5.1/baranus-chaos-forge-1.5.1.jar)

Все версии — на странице [Releases](https://github.com/jangofett158-ops/baranus-chaos/releases). Архивы «Source code (zip / tar.gz)» там — это исходный код, для игры они не нужны: скачивайте `.exe` и `.jar` из блока **Assets**.

> Windows может показать предупреждение SmartScreen, потому что приложение не подписано сертификатом: нажмите «Подробнее» → «Выполнить в любом случае».

## Установка

1. Положите `baranus-chaos-forge-1.5.1.jar` в папку `mods` своего Minecraft (и сервера, если играете на сервере). Нужны Minecraft 1.20.1, Forge 47.4.10+ и Java 17. При совместной игре мод нужен обоим стримерам.
2. Запустите `Baranus-Chaos-1.5.1.exe`

## Подключение

1. **Подключения → «Войти через DonationAlerts».** Откроется браузер, нажмите «Разрешить».
   - Если вход не проходит, создайте своё приложение на [donationalerts.com/application/clients](https://www.donationalerts.com/application/clients) с адресом перенаправления ровно `http://127.0.0.1:3217/oauth/callback` (это адрес вашего же компьютера) и впишите Client ID и Client Secret в «Своё приложение DonationAlerts».
   - Если подписка DonationAlerts в реальном времени не работает, донаты проверяются каждые 5 секунд через список донатов.
2. **Подключения → Minecraft:**
   - **«🏠 Свой мир»** (по умолчанию) — откройте любой мир с модом, приложение подключится само, пароль не нужен.
   - **«🤝 Мир друга»** — играете в мире другого стримера (см. «Совместная игра»).
   - **«🌐 Сервер (RCON)»** — сервер на другом компьютере.
3. **События.** Проверьте цены, переименуйте события под себя или создайте свои.

### Сервер на другом компьютере

Выберите «🌐 Сервер (RCON)» и включите RCON в `server.properties` сервера:

```properties
enable-rcon=true
rcon.port=25575
rcon.password=длинный_пароль
```

## Совместная игра (Radmin VPN)

Оба стримера запускают своё приложение и подключают свой DonationAlerts.

1. Оба устанавливают [Radmin VPN](https://www.radmin-vpn.com/ru/) и заходят в одну сеть.
2. **Хозяин мира:** открывает мир → Esc → «Открыть для сети» (запомните порт из чата), затем в приложении **Подключения → «Совместная игра» → «Разрешить подключение друга»**. Там же видны адрес Radmin (26.x.x.x) и порт доступа — их нужно передать второму стримеру. Если Windows спросит про доступ Java к сети, разрешите.
3. **Второй стример:** заходит в мир через «Сетевая игра» по адресу `адрес_Radmin:порт`, а в приложении выбирает **«🤝 Мир друга»** и вписывает адрес и порт
Настройки событий (цены, валюты, очередь, свои события) хранятся в мире и синхронизируются: правка у любого из стримеров сразу появляется у другого.

- Надписи и эффекты события видят и получают **оба** стримера.
- Мобы и прочие «точечные» события появляются **рядом со стримером, чей зритель задонатил**. Для каждого события это можно поменять в редакторе: «Кому срабатывает» → «Стримеру, которому пришёл донат» или «Всем стримерам в мире».
- Очередь общая: события двух приложений не накладываются друг на друга.

## Как срабатывают события

- Донат **ровно** на сумму цены запускает событие: 20 ₽ — «Зомби». Другие суммы остаются обычными донатами.
- **Очередь.** Событие срабатывает не сразу, а через задержку после доната (по умолчанию 30 с), и между событиями выдерживается пауза (по умолчанию 5 с). Обе настройки — в «События → Очередь». Ожидающие события видны на панели: их можно запустить сразу (▶) или отменить (✕).
- **Зрители из других стран.** В «События → Валюты зрителей из других стран» нажмите на нужные валюты (USD, EUR, UAH, KZT, BYN, PLN, TRY, BRL). Курс подтягивается из интернета автоматически (ExchangeRate-API, обновляется несколько раз в сутки), и цены событий в этих валютах считаются по нему с округлением вверх до числа на 0 или 5 (например, 27 ₴ → 30 ₴, минимум 5). Донат в долларах сравнивается с долларовой ценой. Любую цену можно задать вручную в редакторе события (✎); «Сбросить ручные цены» возвращает расчёт по курсу.
- Если валюта доната не добавлена, приложение берёт пересчёт DonationAlerts в основную валюту (если он есть).
- Если у нескольких событий одна цена, выпадает случайное из них.
- Код в сообщении, например `!creeper`, выбирает конкретное событие, если суммы хватает. Это можно отключить.
- **Пауза хаоса**: кнопка в приложении или клавиша **K** в игре. Донаты во время паузы попадают в ленту, и их можно запустить кнопкой «↻ Запустить».

## Настройка событий

- **Вид:** плитки или список, поиск по названию и сортировка (по порядку, по цене, по названию).
- **«⧉ В отдельном окне»** открывает список событий отдельным окном: там их можно включать, выключать и редактировать, не уходя с панели.
- В редакторе события (✎):
  - **Кому срабатывает** — стримеру, которому пришёл донат, или всем стримерам в мире.
  - **Сила и длительность** — количество мобов, длительность эффекта, уровень и т. п. (у каждого события свои параметры).
  - **Перезарядка** — событие не повторится раньше заданного времени; донат дождётся своей очереди.

## Свои события

**События → «＋ Создать событие»**: название, цена, описание и команды Minecraft, по одной в строке (до 10).

- `{player}` — ник стримера, `{donor}` — имя зрителя.
- Команды выполняются от имени игрока, поэтому `~ ~ ~` означает «рядом с ним». Права как у OP 2-го уровня: `/op`, `/stop` и подобные недоступны.
- Пример: `effect give {player} minecraft:levitation 5 1` и `say {donor} отправил меня в полёт!`
- Кнопка «▶ Проверить» в редакторе сразу запускает событие в игре.

У встроенных событий через «✎» можно поменять название, описание и цену. «Вернуть исходное» отменяет переименование.

## Меню событий в игре (клавиша K)

Все события с ценами из приложения, поиском и вкладками по категориям (Помощь, Пакости, Мобы, Хаос, Свои). Наведите на событие — подсказка покажет описание, кому оно срабатывает и перезарядку.

- **Хозяин мира и OP:** щелчок по событию — проверить на себе (с силой и длительностью из приложения), переключатель — включить или выключить событие. Изменение сразу уходит в приложения обоих стримеров. Внизу — пауза хаоса и «Убрать мобов».
- **Остальные игроки** видят меню только для просмотра.

Мобы получают ник зрителя, а на экране у всех игроков появляется заголовок «Событие — от Ник».

## Разработка

- Node.js 22+: `npm test`, `npm start` (панель в браузере), `npm run desktop`, `npm run dist` (EXE).
- Мод: из папки `forge-mod` командой `gradle build` (Gradle 8.8, Java 17).
- Иконка: `build/icon.ico` (EXE), `public/icon.png` (интерфейс).
