Minecraft-сервер

Запустите Minecraft с модом и откройте любой мир — одиночный или свой сервер на этом ПК. Приложение подключится само, пароль не нужен.

Играете в мире другого стримера через Radmin VPN. Настройки событий подтянутся из его мира автоматически.

Где взять код: у друга, который открыл мир, — в его приложении Baranus Chaos: «Подключения» → «Совместная игра» → включить «Разрешить подключение друга». Там же его адрес Radmin. Это не порт: порт из чата Minecraft нужен только самой игре, чтобы зайти в мир («Сетевая игра» → адрес:порт).

🤝 Совместная игра (Radmin VPN)

Второй стример заходит в ваш мир через Radmin VPN и запускает своё приложение в режиме «Мир друга». Настройки событий общие: правки у любого из вас сразу появляются у другого.

Как зайти в мир через Radmin VPN
  1. Оба установите Radmin VPN и зайдите в одну сеть.
  2. Вы открываете мир: Esc → «Открыть для сети», запомните порт из чата.
  3. Друг в Minecraft: «Сетевая игра» → «Прямое подключение» → ваш_адрес_Radmin:порт.
  4. Включите здесь «Разрешить подключение друга» и передайте другу адрес и код. Windows может спросить разрешение для Java — разрешите.
Как подключить отдельный сервер через RCON

В файле server.properties сервера (остановите сервер перед правкой):

enable-rcon=true
rcon.port=25575
rcon.password=придумайте_длинный_пароль

Мод baranus-chaos-forge-1.5.0.jar положите в папку mods сервера и вашего клиента. Если сервер на этом же ПК, проще выбрать «🏠 Свой мир» — RCON не нужен.
